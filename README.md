# AURELIA — Luxury Watch Website

AURELIA is a modern luxury watch e-commerce website designed with a premium, elegant, and minimal aesthetic.

The website focuses on creating a sophisticated shopping experience through smooth animations, interactive product displays, and a dark black-and-gold visual identity.

## ✨ Features

- Luxury-focused responsive design
- Animated watch collection
- Six men's watch designs
- Product information modal
- Add to Cart functionality
- Interactive shopping cart
- Product search
- Category filtering
- Automatic active navigation while scrolling
- Newsletter subscription section
- Responsive layout for different screen sizes
- Local product images

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Local image assets
- Browser LocalStorage
